How to print correctly (read once)
  1. In the print dialog choose printer ZDesigner ZD230-203dpi, set Margins: None, Scale: 100% (not "Fit to page"), and turn Headers and footers off.
  2. Under "More settings → Paper size", choose the size shown above the preview (for example 103 × 20 mm). If it is missing, add it once in Windows: Printers → ZDesigner → Printing Preferences → Page Setup → New, using the same width × height.
  3. Set the driver to Thermal Transfer (this printer uses a ribbon) and Darkness to about 15–20.
  4. If the print is shifted sideways, change Left offset. If it starts halfway down a label, hold the round button on the printer for about 2 s to calibrate the label sensor, then try again.
  5. Tick Draw label border for the first print. The black box should sit inside each sticker.
  6. Test the barcode with a phone scanner app or the warehouse scanner. If it does not read, choose a thicker bar or a taller barcode.
  7. Show ZPL gives the same label in Zebra's own printer language. Use it as a fallback if browser printing scales the label. Send it with Zebra Setup Utilities → Open Communication with Printer → paste → Send.
